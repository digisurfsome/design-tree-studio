🎨 UI Shuffle - Mockup Editor

How to use:

  1. Select Tool (✂️): Draw rectangles to cut out UI chunks
  2. Move Tool (✋): Drag chunks to rearrange them
  3. Shift+Click: Multi-select chunks, move them together
  4. Resize: Drag corner handles to resize chunks
  5. Ctrl+D: Duplicate selected chunks
  6. Snap to Grid (G): Align chunks to 8/16/32px grid
  7. Ctrl+Mouse Wheel: Zoom in/out
  8. AI (✨): Get smart layout suggestions from Gemini

💡 Smart Fill: Cut areas fill with the actual background color!
